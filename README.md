# Дони Шеф — локальный сайт чайханы

Готовый адаптивный сайт для чайханы в Уфе на улице Ленина, 30. Работает без сборки, npm и серверной базы данных. Все фотографии, оригинальное меню и шрифты сохранены локально.

## Открыть сайт

На macOS дважды нажмите **start.command** — локальный сервер запустится, а сайт откроется в браузере. Окно терминала нужно оставить открытым на время просмотра. Для остановки нажмите `Ctrl+C`. Нужен только Python 3, установка пакетов не требуется.

По умолчанию используется порт 4173. Если он уже занят, скрипт выберет свободный порт и напечатает актуальную ссылку.

Для просмотра через локальный сервер выполните в этой папке:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173. Для остановки сервера нажмите `Ctrl+C` в терминале. Это локальный просмотр, сайт не опубликован в интернете.

Встроенный скрипт можно также запустить вручную: `python3 scripts/serve.py`. Для запуска без автоматического открытия браузера: `python3 scripts/serve.py --no-open`.

## Что реализовано

- На первом экране по кругу меняются три фотографии блюд чайханы с плавным переходом раз в 6 секунд. Есть ручной выбор и пауза; при системной настройке уменьшенного движения автопрокрутка изначально выключена. Смена приостанавливается, когда первый экран не виден или вкладка скрыта.
- 46 позиций: 45 из оригинального меню от 10 сентября 2026 года и оссобуко из публикации от 28 октября.
- Пять категорий исходного меню, просмотр всех позиций и поиск по названию и виду мяса. Поиск не различает регистр и `е`/`ё`; клавиша `/` переводит фокус в поиск.
- Просмотр шести оригинальных страниц меню: увеличение, перелистывание кнопками и стрелками клавиатуры, закрытие по `Escape`.
- Фотогалерея с увеличением и указанием публикации-источника.
- Доставка по подтверждённому телефону, контакты, Telegram, интерактивная карта «ДониШеф» и маршрут в Яндекс Картах. Карта загружается при приближении к разделу контактов и требует интернета.
- Мобильная навигация и закреплённые кнопки меню и доставки; поддержка клавиатуры и уменьшенной анимации.
- Три коротких реальных отзыва гостей перед контактами: авторы указаны, ссылок на оригиналы в публичном блоке нет. Источник для последующей сверки сохранён в SOURCES.md.

## Обновление информации

- `menu-data.js` — названия, категории и цены. Основная публикация хранится в `source`, для более позднего блюда указан индивидуальный источник.
- `index.html` — тексты, контактные данные, ссылки и разметка.
- `styles.css` — оформление и адаптивные размеры.
- `app.js` — поиск, категории, навигация и просмотр изображений.
- `assets/menu/` — шесть неизменённых страниц меню заведения.
- `SOURCES.md` и `assets/provenance.json` — источники и происхождение изображений.

При обновлении меню сверяйте весь соответствующий раздел с публикацией **для Ленина, 30**. Не используйте цены доставки как цены в зале. Не добавляйте вес, состав и фотографии конкретного блюда без подтверждённого источника. После обновления измените дату в примечании под каталогом.

Ссылка Яндекс Еды, опубликованная заведением, 11 ноября 2026 года перенаправляет на главную с `redirectFrom=not_found_place`. Поэтому на сайте используется рабочий телефон доставки. Новую ссылку можно добавить после проверки карточки именно этого филиала.

Корзина, сбор персональных данных и онлайн-оплата не предусмотрены. Сайт не отправляет заявки: телефонные кнопки запускают обычный звонок на устройстве посетителя.
